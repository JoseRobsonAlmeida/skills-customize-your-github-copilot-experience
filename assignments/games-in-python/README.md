
# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Construir um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais e seleção aleatória. Ao final, o aluno deve implementar o fluxo completo de partida com vitória e derrota.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um programa em Python que selecione uma palavra aleatória de uma lista predefinida e permita que o jogador tente adivinhar letras até descobrir a palavra ou esgotar as tentativas.

#### Requisitos
O programa concluído deve:

- Selecionar palavras aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual da palavra no formato `_ _ _`.
- Rastrear a quantidade de tentativas incorretas restantes.
- Encerrar a partida quando a palavra for totalmente adivinhada ou quando as tentativas acabarem.
- Exibir mensagens claras de vitória e derrota ao fim do jogo.
